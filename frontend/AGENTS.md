# Agent notes

This is a standalone TanStack Start application (RSSI Rescue Pod field console).

- Prefer editing source under `src/`; generated files such as `routeTree.gen.ts` are produced by the TanStack router plugin.
- Keep the app runnable with `bun run dev` / `bun run build` after structural changes.
- Do not force-push or rewrite published git history on shared branches.
